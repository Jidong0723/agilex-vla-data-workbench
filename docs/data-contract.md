# 第一阶段动作中间数据约定

## 原始输入与只读原则

输入为本地采集 Episode：`episode.json`、双相机原始帧清单和图像、机器人反馈状态，以及对应 URDF、TCP 偏置和运动学配置。处理结果另存于派生目录，不覆盖原始数据。

## 固定处理顺序

1. 按 `feedback_monotonic_ns` 排序原始机器人状态记录。
2. 使用该 Episode 所引用的 URDF 和 TCP offset，对每条原始 50 Hz 关节反馈独立执行 Pinocchio FK，得到该条记录对应的 TCP 平移与四元数。
3. 在相机与机器人原始流共有的时间范围内建立 20 Hz 目标时刻。外部/腕部相机选取最近帧；关节反馈线性插值；TCP 平移线性插值、四元数采用 SLERP。
4. 保留共同时间范围内可由两侧机器人反馈插值的完整 20 Hz 网格；相机始终取最近帧。记录相机时间误差与机器人反馈跨度，但不作阈值标记或筛除。TCP 位姿与 7 维动作在对齐后计算。

关键语义：TCP FK 先对原始关节样本计算，之后才做时间重采样；不得先插值关节再运行 FK。对齐层的插值只作用于已含 FK TCP 的样本之间。

## 观测数据

每条 `observations.jsonl` 记录包含：

- 对齐帧索引、单调时钟目标时间戳、固定任务文本；
- 外部 RGB 与腕部 RGB 的原始相对路径；
- 对齐后的 7 关节角、关节速度、夹爪实测开度与目标开度；
- FK TCP 的位置、四元数和 Rot6D；原始记录中的 measured/target TCP（仅作审阅对照）；
- `tcp_pair`：本帧与下一连续 20 Hz 帧的 FK TCP 位置、四元数和原始单调时间戳；有效配对还保存 6 维基座系几何增量 `[p_next-p_current, Log(R_next R_current^T)]` 及位姿重建误差。这里的平移是基座系位置差，不是完整 SE(3) twist 的平移对数。两帧的实测夹爪开度与记录的目标开度均保留。遇到对齐缺口或末帧时，`valid=false`、下一位姿和几何增量为空；
- `action.tcp_delta_base`：打标签前为每个有效相邻配对生成 `[Δx, Δy, Δz, rotvec_x, rotvec_y, rotvec_z, absolute_gripper_target]`。夹爪取本帧记录的 `target_gripper_opening_ratio`，按原始反馈时间阶梯保持，不对离散目标线性插值。采集器缺少目标时会以实测开度回退，因此该值不能一概证明为实际下发命令。缺口和原始末帧动作为空；导出手动片段时仅将该片段末帧补为零 TCP 增量、保持夹爪目标。
- 几何增量在打标签前检查数值是否有限，并记录位姿重建误差；不按误差幅度阈值或单步动作幅度筛除实机测得的数据。无法得到有限动作时重算一次，仍失败则标记为无效配对。
- 相机源帧索引、相机时间误差、机器人前后反馈样本索引与时间戳。

LeRobot 格式中间输出将观测状态组织为 `[q1..q7, gripper, tcp_xyz_base, tcp_rot6d_base]` 共 17 维，同时保存 7 维 `action`、两路视频、人工过程任务、20 Hz 本地时间戳和逐帧源索引。`meta/nerovla_tcp_pairs.jsonl` 自包含每个导出 episode 内的相邻 FK TCP 四元数/位置、6 维几何增量及重建误差、夹爪读数和原始时间戳；过程边界的末帧配对无效，不跨段连接。人工审核结果保存在转换 manifest，供第二阶段由人工选择正式数据。扩展 manifest 仍标记 `observation_with_tcp_actions_intermediate`。

## 人工标注与第二阶段边界

`labels.json` 独立保存自然语言过程标题、过程时间范围和人工阶段片段。第一阶段在打标签前计算相邻实测关节 FK TCP 的 6 维几何增量及重建误差，并组合第 7 维夹爪目标；不生成 H16 或归一化统计。人工审核决定哪些数据进入正式训练，不在导出时自动筛除。

原始 `episode.json` 不修改；其中的原始 `task`/`prompt` 另外复制到转换 manifest 的 `raw_episode_task`/`raw_episode_prompt`。`meta/tasks.jsonl` 使用人工界定片段的过程标题。原始数据本来没有逐步 7 维动作标签；派生 `action` 不等同于原始下发命令日志。

第二阶段可从动作中间数据与已审定标签读取：

- 使用第一阶段已计算的 7 维动作；不因实机测得的动作幅度筛除或静默裁剪；执行时的硬件安全限制另行处理；
- 审查夹爪目标的时间关系和来源；采集器可能将缺失目标回退到实测开度，不能从现有原始记录逐帧恢复这一来源差别；
- 在每个连续、合法片段内部生成 H16 训练锚点，拒绝跨任务段、跨时间缺口或包含无效状态的窗口；
- 通过源索引还原原始时间和相机帧对应关系；
- 固定父组 train/validation/test 划分后，仅用训练组计算归一化统计。

含 `action` 的 LeRobot 格式中间视图用于保存、审阅和后续转换；因尚未筛定正式数据、构造 H16 和训练集统计，不应直接用于正式训练。第二阶段应生成独立、含 H16 审计信息的训练数据集，不修改中间数据。
